# 🤖 AI Study Assistant

## 📌 Project Description

The **AI Study Assistant** is a web-based academic assistant designed to help students organize their study activities.

The application accepts a subject, topic, and available study time and generates a personalized study plan, recommended activities, practice questions, and study-progress information.

This beginner version uses rule-based JavaScript to simulate AI behavior. It can later be connected to a real AI model through a secure backend API.

---

## 🎯 Objectives

- Develop a smart study-assistance application.
- Generate personalized study plans.
- Recommend learning activities.
- Generate practice questions.
- Divide available study time efficiently.
- Track study progress.
- Test study-planning functions.
- Simulate AI-assisted learning.
